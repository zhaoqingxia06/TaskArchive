# 听力测试：类型、标准方法与操作流程

> 分类：听觉科学 / 听力学基础知识  
> 更新：2026-11-13  
> 范围：成人听力评估及其对耳机自主测听的启示。本文是专业知识整理，不替代临床诊断。
>
> **标记**：**规范**＝专业指南推荐的常规操作；**条件**＝符合特定临床条件时实施；**可选**＝允许的替代方法或产品设计。不同国家、机构、仪器及患者条件可能不同；“规范”不等于法律强制。

## 1. 听力评估的三个层次

- **筛查**：快速识别可能存在的听力问题，不一定给出完整听阈。
- **诊断性听力评估**：结合病史、耳镜、气导、骨导、言语及其他检查，判断程度、类型和进一步检查需求。
- **助听验配与验证**：在评估基础上配置增益、压缩及输出限制，借助真耳测量和言语表现等验证效果。

## 2. 常见测试类型及流程总览

| 测试 | 刺激与设备 | 用户反馈 | 标准/典型流程 | 主要输出 |
|---|---|---|---|---|
| 气导纯音测听 | 校准耳机播放单频纯音 | 听到即按键 | 说明与熟悉→逐频率升降声级寻阈→重复确认→双耳记录 | 各频率气导听阈（dB HL） |
| 骨导纯音测听 | 乳突或额部骨振动器 | 听到即按键 | 放置骨振动器→寻阈→按需掩蔽→记录 | 骨导听阈；结合气导识别气骨导差 |
| 言语测听 | 标准化词表、语音材料 | 复述/识别 | 选择材料和声级→播放→评分→按目标测SRT或词语识别率 | 言语接受阈值/识别率 |
| 噪声中言语测听 | 言语与背景噪声 | 复述/选择 | 设定噪声→呈现言语→改变信噪比或固定条件→评分 | SNR阈值或固定条件正确率 |
| 鼓室图/声导抗 | 密封探头、探测音和压力变化 | 通常无需反馈 | 耳镜→密封探头→压力扫描→测量声学导纳 | 鼓室图及中耳相关指标 |
| 耳声发射 OAE | 耳道探头播放刺激并录音 | 无需主动反馈 | 耳镜→安静佩戴探头→刺激与采集→信噪比/重复性分析 | 耳蜗外毛细胞相关反应 |
| 听觉脑干反应 ABR | 声刺激、电极记录 | 通常无需主动反馈 | 皮肤准备及电极→声刺激→重复采集波形→判读 | 听觉脑干通路反应；特定方案可估计听阈 |

> 前四种主要是行为测试，后三种主要是客观生理测试。各方法不能互相完全替代。

## 3. 气导纯音测听：详细标准流程

### 3.1 测试前准备

| 要求 | 操作 | 属性 |
|---|---|---|
| 环境 | 控制背景噪声；允许噪声值须依据目标最低测试声级、耳机类型和频率范围，参考 ISO 8253-1、ANSI/ASA S3.1 | 规范 |
| 仪器 | 使用经校准的听力计、换能器和匹配的参考等效听阈声压级 | 规范 |
| 耳部状态 | 询问相关病史，检查外耳道是否堵塞及耳部异常 | 规范 |
| 佩戴 | 耳机正确定位，避免耳道压闭、漏声及干扰 | 规范 |
| 说明 | 听到再微弱的声音也反馈；只在确实听到时响应 | 规范 |
| 熟悉 | 常以1000 Hz明显可听声建立任务理解 | 推荐 |
| 环境噪声自动检测 | 消费耳机用麦克风检查背景噪声 | 产品可选；不能替代完整声学校准 |

### 3.2 寻阈步骤

1. **选择测试耳**：已知较好耳时通常先测较好耳；未知时可依规程选择。**规范推荐**
2. **1000 Hz熟悉**：播放可明确感知的纯音，确认理解。**规范推荐**
3. **寻找阈值**：采用经典 Hughson–Westlake 类阶梯法，通常听到下降10 dB、未听到上升5 dB；具体起始与呈现规则依规程。**BSA/ASHA规范方法**
4. **重复确认**：BSA常用判据是在上升试次中，同一最低声级至少两次反应，且达到规定的反应比例。**规范**
5. **切换频率**：常规可覆盖250、500、1000、2000、3000、4000、6000、8000 Hz；BSA推荐从1000 Hz起，先测高频再测低频，并复测1000 Hz。**规范推荐**
6. **复核**：核对1000 Hz复测一致性；不一致则排查理解、注意力、设备等问题。**规范**
7. **另一耳**：重复上述流程。**规范**
8. **必要时掩蔽**：根据耳间衰减、气骨导结果和交叉听取风险判定，而非仅看左右耳差异。**条件**
9. **记录**：左右耳各频率dB HL、未反应点、掩蔽状态、设备/换能器及可靠性。**规范**

**示例（非真实患者数据）**：1000 Hz从30 dB HL听到开始，降到20听不到，升到25听到；继续重复下降10/上升5，若25 dB HL满足上升试次反应判据，则记录该频率听阈25 dB HL。不能把首次听到的声级直接当成最终阈值。

### 3.3 条件性补测与异常处理

- 相邻倍频程听阈相差约20 dB或以上时，依据采用的规程决定是否增加中间频率；注意**相邻频率差值**与**某频率绝对听阈超过20 dB HL**不是同一概念。**条件**
- 怀疑低频异常时补测125 Hz。**条件**
- 耳鸣干扰时可选择脉冲音或啭音。**可选**
- 用户误按、疲劳或反应不可靠时重新指导、休息、复测或记录偏离。**条件**
- 设备最大输出仍无反应时记录“无反应”及输出上限，不编造听阈。**规范**

## 4. 其他测试的具体方法

### 4.1 骨导纯音测听
1. 检查耳部情况，正确放置骨振动器于乳突（或依规程放额部），避免接触耳廓。**规范**
2. 用校准的骨导刺激按频率逐步寻阈，用户听到即反馈。**规范**
3. 依据气骨导差、非测试耳阈值及交叉听取风险实施掩蔽；骨导刺激可能被双耳感知。**条件**
4. 记录各频率骨导阈值及掩蔽情况，与气导结果结合判断传导性、感音神经性或混合性听损。**规范**

### 4.2 言语测听
1. 选择与用户语言、年龄和能力匹配的**标准化**词表、录音材料及校准播放方式。**规范**
2. **言语接受阈值 SRT**：改变呈现声级，寻找按指定正确率标准能够识别的最低水平；常用双音节词等材料，具体取决于语言和规范。**标准方法之一**
3. **词语识别率 WRS**：在选定的适宜声级播放标准词表，统计复述正确率；必要时多声级测试。**标准方法之一**
4. 按左右耳、声级、材料、正确率记录结果。**规范**
5. 在助听前后比较表现时控制声级、词表难度和学习效应。**条件**

### 4.3 噪声中言语测试
1. 选用经验证的数字、词语或句子材料及标准背景噪声。**规范化测试前提**
2. 设定声场或耳机播放方式、言语声级与噪声声级。**规范化测试前提**
3. 呈现语音与噪声，让用户复述或选择内容。**标准流程**
4. 采用固定信噪比测正确率，或自适应改变信噪比以寻找规定正确率的SNR阈值。**两种可选测试方案**
5. 输出结果时标注测试材料、语言、噪声类型、播放条件、计分方法。**规范化报告要求**
> 不同测试（如QuickSIN、HINT、Digits-in-Noise）流程、评分和阈值定义不同，不应混用。

### 4.4 声导抗与鼓室图
1. 耳镜检查耳道与鼓膜，排查禁忌或影响密封的情况。**规范**
2. 选择合适探头并密封耳道。**规范**
3. 仪器播放探测音、改变耳道压力并记录声学导纳变化。**鼓室图标准流程**
4. 输出鼓室图、峰压、顺应性/导纳等指标，结合耳镜和其他检查解读。**规范**
5. 声反射阈值、衰减测试等属于声导抗相关扩展项目，按临床指征进行。**条件**

### 4.5 耳声发射 OAE
1. 耳镜检查、控制环境及生理噪声，选用合适探头。**规范**
2. 依据方案选择瞬态诱发OAE（TEOAE）或畸变产物OAE（DPOAE）。**可选测试类型**
3. 仪器播放刺激声并采集耳道微弱声学反应。**标准流程**
4. 按频率、信噪比、噪声底、重复性和设备判定标准评价反应。**规范化要求**
5. 结合中耳情况解释结果；OAE不能单独提供完整行为听阈，也不能排除所有听觉神经通路问题。**解释限制**

### 4.6 听觉脑干反应 ABR
1. 评估适应证，选择适宜的安静/睡眠状态；准备皮肤并粘贴电极，检查阻抗。**规范**
2. 通过耳机给予点击声或频率特异性短声/调频短音等刺激。**依目的选择**
3. 多次叠加采集、复核波形重复性及伪迹。**规范**
4. 观察波形潜伏期、形态及阈值相关反应；必要时改变刺激强度寻找最低可重复反应。**依目的选择**
5. 结合年龄、刺激类型、传导状态和其他听力学结果解释。**规范**
> ABR测得的是诱发电反应阈值或神经传导信息，不可不经换算直接当作常规纯音气导听阈。

## 5. 方法间的核心区别

| 维度 | 气导/骨导纯音 | 言语 | 噪声中言语 | 鼓室图 | OAE | ABR |
|---|---|---|---|---|---|---|
| 测量目标 | 最低可听声级 | 言语理解 | 噪声干扰下的理解 | 中耳功能 | 耳蜗外毛细胞相关反应 | 听觉脑干反应 |
| 用户主动反馈 | 是 | 是 | 是 | 否 | 否 | 否 |
| 主要变化参数 | 频率、声级 | 声级/词表 | 信噪比 | 耳道压力 | 刺激类型/频率 | 刺激强度/类型 |
| 能否直接形成纯音听力图 | 是 | 否 | 否 | 否 | 否 | 不能直接等同 |
| 对耳机辅听的用途 | 增益拟合基础 | 理解效果验证 | 嘈杂场景验证 | 排查中耳因素 | 辅助评估 | 特定临床评估 |

## 6. 消费级耳机产品的设计启示（非临床规范）

- **基础测听**：以校准气导纯音阈值为核心；环境噪声、佩戴密封性、换能器声学校准、可靠性复测是关键。
- **寻阈算法**：可参考10 dB下降/5 dB上升的经典方法，其他自适应算法必须通过对照验证。
- **效果验证**：增加言语识别及噪声中言语测试，区分“听得到”和“听得懂”。
- **导入听力图**：校验左右耳、频率、单位、气导/骨导、来源及缺失值。
- **风险边界**：仅有气导阈值不能完成病因诊断；出现突发、单侧明显异常、耳痛等情况应提示专业评估。
- **助听拟合**：不能直接按损失dB数等量补偿；还涉及验配公式、压缩、最大输出及安全验证。
